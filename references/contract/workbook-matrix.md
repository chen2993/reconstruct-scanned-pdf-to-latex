# 做题本矩阵

做题本是**同一份语义源码的视图和版式参数组合**，不是复制一套页面源码。例题和习题使用独立计数器、独立筛选键和独立答案归属；全做题本同时保留两类题目。

## 0. 先理解做题本要解决什么

原书里「题目」和「解答」是排在一起的。做题本要把它变成**只有题目、留出书写空间**的版本，供人刷题。因此要做三件事：

1. **隐藏答案子树**，但题目、编号、必要媒体照旧；
2. **按被隐藏的答案高度预留作答空间**——答案越长，留白越多（这是做题本好不好用的关键）；
3. **重新排布**，让每题及其作答区不被拆页。

第 2 点是这项功能的核心，也是最容易做错的地方。它不是"每题留固定几厘米"，而是**量出答案的实际高度再按比例预留**。真实做法见第 4 节。

## 1. 目标矩阵

| 目标 | 题目范围 | 纸张 |
|---|---|---|
| 完整书 | 原书全部内容，答案可见 | `original` |
| 例题做题本 | 例题题干和必要媒体，隐藏答案 | `original`, `a4`, `pad11`, `pad13` |
| 习题做题本 | 习题题干和必要媒体，隐藏答案 | `original`, `a4`, `pad11`, `pad13` |
| 全做题本 | 例题与习题题干和必要媒体，隐藏答案 | `original`, `a4`, `pad11`, `pad13` |

没有对应题型或用户未要求时，不生成空目标。每个目标还可选主题；默认矩阵只固定用户确认的 `print` 与护眼黄 `eyecare`，项目实现别的主题时才加入。主题是**整组配色**（底色、框色、表格线、链接色一起走），不是只换页面背景，暗底主题不得沿用亮蓝链接或刺眼金色。

参考 `template/build.ps1` 的 `matrix` 目标会为用户确认的主题集合生成完整书与做题本目标；做题本题型同样显式选择，只有传入实际存在的范围才生成：

```powershell
./build.ps1 -Target matrix -Scope examples,all
./build.ps1 -Target matrix -Scope examples -Themes print,eyecare,dark
```

省略 `-Scope` 时只生成完整书目标。单目标 `-Target workbook` 只接受一个范围。Windows 下 `-Scope`、`-Themes` 支持 `a,b` 逗号写法。

## 2. 入口形态：两种都可以，按差异大小选

做题本与完整书共享同一份**题目内容**，但入口如何组织有两条成熟路线，**都可行**。选择依据是"做题本与完整书的差异有多大"：

### 形态 A：单入口 + 类文件开关

`main.tex` 是唯一入口，做题本差异全部由 `.cls` 的开关与条件命令控制。

```tex
% main.tex
\providecommand{\BookBuildOptions}{book,print}
\edef\BookApplyBuildOptions{\noexpand\PassOptionsToClass{\BookBuildOptions}{projectclass}}
\BookApplyBuildOptions
\let\BookApplyBuildOptions\relax
\documentclass{projectclass}
\begin{document}
\input{front/cover}
\ifbookworkbook
  \BookWorkbookToc
\else
  \input{front/preface}
  \input{front/toc}
\fi
\bookinput{1}{584}
\end{document}
```

- **适合**：做题本与完整书的**封面、前言、目录大体相同**，差异集中在题目筛选与答题区；
- **优点**：单一入口，模块清单静态可审计，不会出现两套事实；
- **代价**：入口里的条件分支会随差异增多而变复杂。

### 形态 B：独立做题本入口

做题本有自己的 driver 与自己的前后置模块，题目内容仍复用同一份源码。

```tex
% main-workbook.tex —— 只定义选项并加载同一份体例
\providecommand{\bookbuildtheme}{print}
\providecommand{\bookworkbookprofile}{a4}
\documentclass{projectclass}
\booksetcontentmode{workbook}
\booksetworkbookprofile{\bookworkbookprofile}
\begin{document}
\booksettheme{\bookbuildtheme}
\bookfrontmatter
\input{front/workbook-cover}     % 做题本专用封面模块
\booktableofcontents
\bookmainmatter
\bookinputpages{11}{584}         % 与完整书同一份正文源码
\end{document}
```

- **适合**：做题本的**封面、目录、页眉页脚与完整书差异很大**（例如做题本要专门的封面标识、只列题目范围的目录、按画布重排的页眉）；
- **优点**：差异用独立模块表达，不必往入口塞条件分支；做题本封面可以完全重新设计；
- **约束**：**题目内容仍必须是同一份源码**。独立的是入口与前后置模块，不是题目。

### 两种形态的共同底线

无论哪一种，以下事实**只能有一份**：

- **题目与答案的内容**：不得为做题本复制题目源码、另写题号或另存一份正文；
- **类文件**：题目环境、筛选开关、答题区算法都在同一个 `.cls` 里；
- **正文页源码**：`pages-xxx.tex` 只有一份，两个目标各自 `\bookinput`/`\bookinputpages` 同一范围。

**由用户决定用哪种形态。** 差异小选 A，差异大选 B；不要两种混用（例如既有 `main-workbook.tex` 又在 `main.tex` 里写做题本分支）。

## 3. 版式契约

- **自然流动（`original` / `a4`）**：题目与作答区向下自然排版；同一个完整逻辑题目**连同其作答区**不得跨页——放不下就把整题移到下一页。
- **一页一题（`pad11` / `pad13`）**：题干、必要图形和作答区必须同页；作答区吃掉本页剩余空间后强制换页。
- 做题本保留完整题干、解题必需媒体和题目编号；隐藏答案、解析、提示、证明及答案专属媒体。
- 跨页题目使用一组 `\begin`/`\end`（跨页续写用同一环境的续写形式）；编号只在起始处建立，作答区只在题末产生**一次**，不重复留白。
- 父题目隐藏时嵌套答案不可能单独出现；父题目可见而答案关闭时只隐藏答案子树。
- 原书的前后置模块按形态 A/B 复用或改用专用模块；**横向纸型只调整画布和坐标**，不复制另一套内容或把整页 A4 图像缩放后导入。
- 做题本不承载原书章节标题块：part/chapter 只进页眉页脚（含第一页），正文里不再重排一遍大标题占版面。隐藏正文标题与隐藏页眉页脚是**两个独立开关**。
- 做题本页眉页脚同样覆盖第一页，并按画布重新定位，不沿用完整书的双面 `LE/RO` 几何。

## 4. 作答区：隐藏—测量—预留

这是做题本的核心机制。两个成熟的实现（`test` 与 `epsilon-delta`）算法一致，具体如下。

### 4.1 三步流程

```
① 隐藏答案时：把答案内容吸入盒子，量出高度，写入 .aux（按题目编号作键）
② 排版题目时：预留高度 = clamp(实测高度 × 缩放系数, 下限, 上限)
③ 放置：若预留高度 > 本页剩余空间 → 整题移到下一页；否则在本页留出该空间
```

**必须两遍编译**：第一遍量高并写入辅助文件，第二遍才读到高度并正确预留。构建脚本的 `-Passes 2..3` 就是为这类收敛设计的。

### 4.2 隐藏但可测

隐藏分支里内容**必须仍被排版**，否则量不到高度、动态预留就无从谈起：

```tex
\newif\ifBookShowAnswers
\newsavebox{\BookAnswerProbe}
\newlength{\BookMeasuredAnswerHeight}
\newenvironment{bookanswer}{%
  \ifBookShowAnswers
    \par\begin{bookanswerbox}%          % 显示：正常排版
  \else
    \setbox\BookAnswerProbe=\vbox\bgroup  % 隐藏：吸入盒子（可测、不输出）
  \fi
}{%
  \ifBookShowAnswers
    \end{bookanswerbox}%
  \else
    \egroup
    \global\BookMeasuredAnswerHeight=\dimexpr
      \ht\BookAnswerProbe+\dp\BookAnswerProbe\relax
  \fi
}
```

- 用 `\setbox…\vbox\bgroup` 路线，**不要用 `comment` 类宏包**——后者跳过排版，拿不到高度；
- 一题可能有**多个**答案块（分步解答），高度要**累加**；
- 跨页题的续写段也要计入同一题的高度。

### 4.3 预留高度：clamp 到区间，并放大一点

```
预留 = 实测高度 × 缩放系数
预留 = max(预留, 下限)      % 答案很短时也要有基本书写空间
预留 = min(预留, 上限)      % 答案很长时不独占整页
预留 = min(预留, 本页可用高度)  % 再按当前页实际余量收口
```

两个实现采用的数值（**起点，不是定值**）：

| 参数 | 典型值 | 含义 |
|---|---|---|
| 缩放系数 | `1.15` | 比答案略大，留出书写余量 |
| 下限 | `0.18\textheight` | 答案极短时的基本空间 |
| 上限 | `0.46\textheight` | 答案极长时不独占整页 |

**这些数值必须按原书的作答空间实测调整**：原书若给人留大半页，就调大上限；原书是紧凑型，就调小。不要直接套用。

### 4.4 放不下时：整题移页，不要留下隐形胶

预留空间**放不进本页剩余**时，有两种错误做法：把不可见的 glue 带到下一页（下一题会莫名其妙地开始于页面中部），或强行压缩作答区。正确做法是**整题移到下一页**：

- **自然流动**：排版前用 `\Needspace{题目高度 + 预留高度 + 间距}` 请求足够空间，LaTeX 自动把整题推到下一页；
- **一页一题**：作答区直接 `\vfill` 吃掉本页剩余后强制换页；
- **更精细的做法**：显式比较"预留高度"与"本页剩余"（`\pagegoal - \pagetotal`），放不下时 `\nobreak\vfill\newpage` —— 用尽本页剩余并显式结束这一页，而不是让胶体流到下一页；
- 若"题目本身 + 最小作答区"都超过一整页，报错或按项目约定回退，**不能静默缩小题干字体**。

### 4.5 两条代码路径

一页一题与自然流动是**不同的实现路径**，不是同一个开关：

| | 自然流动（`original`/`a4`） | 一页一题（`pad11`/`pad13`） |
|---|---|---|
| 作答区 | 固定高度的盒子（clamp 后的预留值） | `\vfill` 吃掉本页剩余 |
| 分页 | `\Needspace` 请求整题空间 | 作答后强制换页 |
| 题目高度 | 参与 `\Needspace` 计算 | 不参与（本页只放一题） |
| 页面几何 | 沿用原书版心（或 A4 重排） | 横向画布，页眉页脚按画布重定位 |

## 5. 纸张与尺寸检查

纸型尺寸只有一份来源：`scripts/build_profiles.py`（内置 `a4`/`pad11`/`pad13`）与项目登记的 `profile-overrides.json`（`original` 及项目自订纸型）。`.cls` 与成品审计都读它，不要在两处各写一套。`original` 未登记时构建审计**报错**，不会退回某个常见开本。

| profile | 目标尺寸 | 方向 |
|---|---|---|
| `pad11` | 280 mm × 193 mm | 横向 |
| `pad13` | 280 mm × 210 mm | 横向 |
| `a4` | 210 mm × 297 mm | 纵向 |
| `original` | 项目确认的原书尺寸 | 由原书决定 |

构建后读 PDF MediaBox 逐页核对，而不是只看类文件参数。

## 6. 前后置模块与书签

所有目标复用同一套自动目录与 PDF outline 接口：`scripts/audit_toc.py` 强制目录模块只调用一次 `\bookmaketoc`、入口只导入一次目录模块；每个目标的 PDF outline 覆盖原书实际存在的各前后置模块书签。不得为不同目标手工复制目录或硬编码书签页码。

形态 B 下做题本有自己的封面/目录模块，此时该模块同样是"原书实际存在的模块"之一，需要登记。

## 7. 答案隔离必须在成品上验证

不能只看 `.cls` 的显示开关——**开关写对了不等于成品没有泄题**（跨页续写、浮动体、目录页眉都可能漏出去）。准备一份哨兵清单（答案、解析、提示、证明中的独有短句），用 `-AnswerSentinels <file>` 传入；`scripts/audit_pdf_build.py` 逐页比对并拒绝命中的目标。做题本目标缺少哨兵清单时**构建直接失败**——没有哨兵就没有证据。

## 8. 产物命名

多目标发布时，文件名要能一眼看出纸型、主题、用途，并带书名前缀，例如 `[pad13][护眼版][做题本] 书名.pdf`、`[a4][做题本] 书名.pdf`、`[原书版] 书名.pdf`。完整书不带做题本标记。命名由构建脚本从目标轴自动拼装；同一目标重复构建必须得到同名产物。

## 9. 必测组合

至少验证：

- 完整书 `original/print`；
- 三种做题本各自的 `original/print`；
- 四种纸张下的一页一题与自然流动行为；
- `eyecare` 主题；
- 嵌套答案隐藏（父题可见、答案关闭）；
- 例题与习题独立筛选；
- **一个语义题目跨两个 `pages-xxx.tex` 文件时只生成一次作答区**；
- **动态作答区**：短答案与长答案的留白明显不同，且长答案不独占整页；
- **两遍编译收敛**：第二遍的作答区高度与第一遍实测一致（`Rerun` 消失、无 `Label(s) may have changed`）。

每个目标至少一次强制重编与一次缓存重编；后一次必须命中独立目标缓存且输出集合、页数与命名不漂移。
