# 做题本矩阵

做题本是同一份语义源码的视图和版式参数组合，不是复制一套页面源码。例题和习题使用独立计数器、独立筛选键和独立答案归属；全做题本同时保留两类题目。

## 目标矩阵

| 目标 | 题目范围 | 纸张 |
|---|---|---|
| 完整书 | 原书全部内容，答案可见 | `original` |
| 例题做题本 | 例题题干和必要媒体，隐藏答案 | `original`, `a4`, `pad11`, `pad13` |
| 习题做题本 | 习题题干和必要媒体，隐藏答案 | `original`, `a4`, `pad11`, `pad13` |
| 全做题本 | 例题与习题题干和必要媒体，隐藏答案 | `original`, `a4`, `pad11`, `pad13` |

没有对应题型或用户未要求时，不生成空目标。每个目标还可选择主题；默认矩阵只固定用户确认的 `print` 与护眼黄 `eyecare`，项目实现别的主题（例如深色）时才加入。主题决定底色、框色、表格线和链接色整组配色，不是只换页面背景，暗底主题不得沿用亮蓝链接或刺眼金色。若实际 `.cls` 提供语义小节强制分页接口，再为做题本增加 `section_break=false|true` 两个变体；这不是完整书维度，也不能凭空加入不存在的接口。

参考 `template/build.ps1` 的 `matrix` 目标会为**用户确认的主题集合**生成完整书和做题本目标；做题本题型同样是显式选择的，只有传入实际存在的范围才会生成。默认主题集合是 `print` 和 `eyecare`，项目实现了其它主题时才用 `-Themes` 传入完整集合（必须包含 `print`），不把额外主题当成默认交付。例如：

```powershell
./build.ps1 -Target matrix -Scope examples,all
./build.ps1 -Target matrix -Scope examples -Themes print,eyecare,dark
```

省略 `-Scope` 时只生成完整书目标，不会猜测或生成例题/习题做题本。单目标 `-Target workbook` 必须只传一个 `-Scope`。Windows 下 `-Scope`、`-Themes` 都支持 `a,b` 逗号列表写法。
参考脚本以 `-RequiredBookmarks` 接收**本项目实际拥有的前后置模块清单**（`key=显示标题`，按原件顺序），校验每个模块的顶层书签及其非空目标页。清单不是固定的：原件有献词就登记献词，没有就不登记；漏登记等于漏提取。双语或定制显示文本只改等号右侧标题。该检查读取 PDF outline 和目标页渲染，需要 Python/PyMuPDF，不读取正文文字。

## 版式契约

- `original` 和 `a4`：题目与答题区自然向下排版，但同一个完整逻辑题目及其答题区不得跨页。
- `pad11` 和 `pad13`：一页一题；题干、必要图形和答题区必须同页。
- 做题本保留完整题干、解题必需媒体和题目编号；隐藏答案、解析、提示、证明及答案专属媒体。
- 跨页题目使用一组 `\begin`/`\end`；编号只在 `\begin` 建立，答题区只在 `\end` 产生一次，不重复留白。
- 父题目隐藏时嵌套答案不可能单独出现；父题目可见而答案关闭时只隐藏答案子树。
- A4/原书尺寸的答题区按题目和隐藏答案测量结果动态预留；题干与答题区无法同页时整题换页，不能缩小题干字体。Pad 目标不得把动态答题区挤到下一页。
- 原书的各前后置模块（封面、献词、目录、末页等，以原件为准）沿用同一组内容模块；横向纸型只调整画布和坐标，不复制另一套内容或把整页 A4 图像缩放后导入。
- 做题本不承载原书的章节标题块：part/chapter 只放进页眉页脚（含第一页），正文里不再重复排一遍大标题占版面。隐藏这些正文标题不等于隐藏页眉页脚信息——两者是独立的显示钩子。
- 做题本的页眉页脚同样要覆盖第一页，并按画布重新定位，不沿用完整书的双面 `LE/RO` 几何。

## 纸张检查

`original` 必须由用户确认的原书尺寸驱动，不能从参考项目套用；常用做题本 profile 的目标尺寸为：

| profile | 目标尺寸 | 方向 |
|---|---|---|
| `pad11` | 280 mm × 193 mm | 横向 |
| `pad13` | 280 mm × 210 mm | 横向 |
| `a4` | 210 mm × 297 mm | 纵向 |
| `original` | 项目确认的原书尺寸 | 由原书决定 |

构建后检查 PDF MediaBox，而不是只检查类文件参数；原书尺寸若未确认，暂停构建并询问用户。

所有目标都必须复用同一套自动目录和 PDF outline 接口：`scripts/audit_toc.py` 强制目录模块只调用一次 `\bookmaketoc`、入口只导入一次 `front/toc`，结构命令自动产生目录条目和结构书签；每个目标的 PDF outline 都要覆盖原书实际存在的各前后置模块书签。不得为不同目标手工复制目录或硬编码书签页码。

做题本的答案隔离必须由构建脚本在成品上验证，不能只看 `.cls` 的显示开关。准备一份哨兵清单（答案、解析、提示、证明中的独有短句），用 `-AnswerSentinels <file>` 传入；`scripts/audit_pdf_build.py` 会逐页比对并拒绝任何命中的目标。做题本目标缺少哨兵清单时构建直接失败——没有哨兵就没有证据，而目视抽查覆盖不了全书。

## 产物命名

多目标发布时，成品文件名必须能一眼看出纸型、主题和用途，并带书名前缀，例如 `[pad13][护眼版][做题本] 书名.pdf`、`[a4][做题本] 书名.pdf`、`[原书版] 书名.pdf`。完整书不带做题本标记。命名由构建脚本从目标轴自动拼装，不手工命名；同一目标重复构建必须得到同名产物，不能因缓存或调用方式改变而漂移。

## 入口参数

```tex
% driver.tex; all targets eventually input the same main.tex
\def\BookBuildOptions{workbook,examples,pad11,eyecare}
\input{main}
```

完整书 driver 例如 `\def\BookBuildOptions{book,print}`。项目 `.cls` 应把这些选项映射到集中视图和样式钩子；入口模块清单保持静态，必要的前后置差异在模块内部用公共条件命令控制。页面文件不应根据目标写条件分支，也不应复制题目或答案。

## 必测组合

至少验证：完整书 `original/print`；三种做题本各自的 `original/print`；四种纸张中的一页一题与自然向下行为；`eyecare` 主题；嵌套答案隐藏；例题和习题独立筛选；一个语义题目跨两个 `pages-xxx.tex` 文件时只生成一次答题区。若实现 `section_break`，再验证 `false/true × simple/normal`，并确认隐藏标题仍能分页、Pad 不产生孤立标题或空白页。

每个目标至少进行一次强制重编和一次不改源码的缓存重编；后一次必须命中独立目标缓存且输出集合、页数和目标命名不漂移。结构迁移（例如合并前置模块或重组图形库）前后保存代表页和整本 PDF 基线，确认变化只来自预期路径或样式调整。
