# 样式提取（并行）

样式卡片的质量决定后面几百页的返工量。样式提取是**读大量代表页**的活，正好适合并行；但并行读页又会撞上上下文与图文错配问题，所以需要一个固定顺序。

## 0. 顺序：先目录，再代表页，最后汇总扩样

四步，顺序不可颠倒：

1. **先看目录，了解页面分布**。目录页告诉你"全书有哪些类型、大致落在哪些页"。这一步只需 1–2 张总览图，不要逐页看。
2. **再按类型派发代表页**：多种类型并行去看，每类一张代表页，各自返回该类型的可见特征。
3. **汇总**：把各单元返回的特征合并成样式卡片，检查有没有冲突或遗漏的类型。
4. **补充扩样**：针对有疑问的类型，**额外看连续的前几页**（例如某章开头连看 3–5 页），确认该类型是否稳定、有没有变体。

第 4 步最容易被省掉，但它恰恰是发现"同类型不同变体"的唯一机会——只抽一张代表页会把变体当成噪声忽略。

## 1. 第一步：从目录建类型清单

用 `scripts/crop_page.py --overview` 看目录页，列出**实际存在的**页面类型。常见清单：

封面、版权/出版信息（证据页）、献词/序言、目录、章节首页、知识结构图页、普通正文、例题页、习题页、答案/解答页、图表/公式密集页、参考文献/索引/附录、封底/书末页。

要点：

- **只登记原件实际存在的类型**；教材没有例题就不要为了填清单而假设有；
- 目录同时给出**结构落点**（各章、各习题集从哪页开始），这是后面派发时的"结构地图"，见第 4 节；
- 目录页若只有一两页，用总览看完即可，不必裁块精读。

## 2. 第二步：按类型并行派发代表页

**每类一张代表页**，多个类型同时派发。每个单元的任务只包含：一个类型名、一张页图、要求返回的字段。

单元返回格式固定，便于汇总：

```text
TYPE: 例题页
代表页: pages-041
可见特征: 题号「例 1.2」宋体加粗、题干通栏、解答左缩进两字、题间留白约一行
疑似变体: 本页出现「例 1.2*」，带星号，可能表示超出大纲
存疑: 解答前的「解」字是否为独立行，需看相邻页确认
```

**派发纪律**（与 [page-reading.md](page-reading.md) 一致）：

- 每个单元只裁**自己那一页**，用 `--overview` 定位 + `--region` 精读，受每页读图预算约束；
- 裁图文件名带页号前缀，避免并发覆盖；
- 不要给单元"顺便看看别的页"的模糊指令——那会突破预算，也会污染它的类型判断。

## 3. 第三步：汇总成样式卡片

把各单元的返回合并进 `style-cards.md`，逐条对照：

- **冲突**：同一类型两页返回不同特征 → 说明该类型有变体，或代表页选得不对。回到第 4 步扩样确认，不要随手取一个。
- **遗漏**：目录里出现的类型没有任何单元回报 → 补派一个单元。
- **过细**：单元把偶发差异（某页多一个空行）当成样式特征 → 归入"待复核"，不进卡片。

汇总后每条卡片必须写明：样式 ID、页面分型、语义角色、环境或命令、可见特征、辨识条件、显示视图、代表页标识、状态。

## 4. 第四步：补充扩样

对有疑问或刚合并的类型，**连续看前几页**确认稳定性：

- **章节首页类**：连看某章开头 3–5 页，确认章首版式（章号、章名、知识结构图的位置）是否每章一致；
- **题目类**：连看一节的 4–6 页，确认题号连续性、有无带星号变体、答案是否紧跟题目；
- **跨页类**：连看 2–3 页，确认跨页对象的框线与标题是否只在起始页出现一次。

扩样只针对**有疑问的类型**，不要全书铺开——那是一整轮转写的开销。

**同时产出结构地图**：扩样时顺手记下各章/各习题集/综合题的**起始页与对应结构命令**，写成派发材料（例如 `dispatch/STRUCTURE.md`）。转写单元靠它核对"我这页是不是某一节的第一页"，避免把结构命令写错位置。结构地图是派发材料，不写进页面源码。

## 5. 并行度与顺序的取舍

- **可以并行**：不同**类型**的代表页（互不依赖，读的是不同页）；
- **不宜并行**：同一类型的多张代表页**首轮**不要并发——先把类型判断收敛到一张，再有疑问时扩样；
- **必须串行**：汇总是单点判断，不能并行写 `style-cards.md`。

典型节奏：

```text
目录总览（1 次）
  → 并行派发 N 个类型代表页（N = 类型数，通常 6–12）
    → 汇总（串行）
      → 对有疑问的 2–3 个类型扩样（并行 2–3 个）
        → 定稿 style-cards.md + 结构地图
```

## 6. 样式与"native"的关系

样式提取的目标是**还原原书**，不是套用模板：

- 字体族、字重、缩进、留白、题号形式**都从代表页实测**；不要因为某本模板用楷体做评注就假定本书也是；
- 参考其它项目（例如开源做题本文档类）只能借鉴**维度清单**（有哪些可配置轴），不能搬它的数值；
- 原书同一类型在不同章节有差异时，记录为变体并说明分布，而不是强行统一成一种。
