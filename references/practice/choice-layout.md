# 选择题排版与工具策略

## 1. 目标

中文教材中的选择题同时包含三件事：选项内容、标签生成、版式决策。三者必须分开：

- 页面源码只提供四个选项内容；
- `A.`、`(B)` 或 `（C）` 由项目 `.cls` 的计数器生成；
- 四列、二二、竖排、公式版和图文版由同一个接口的模式决定。

参考项目提供的是三种可复用的设计思想，而不是可直接复制的视觉参数：

- `test`：用列表语义和悬挂缩进表达普通短选项；
- `epsilon-delta`：用固定 `p{...}` 列宽保证网格稳定，公式、矩阵和图形选项使用专门版式；
- `jjb`：先测量最宽选项，再在四列、二二和逐行之间选择，并把列宽、标签宽、间距集中管理。

## 2. 唯一入口

项目类文件应实现：

```tex
\bookchoices{选项一}{选项二}{选项三}{选项四}
```

默认模式是 `auto`，固定模式是：

```tex
\bookchoices[mode=four]{...}{...}{...}{...}
\bookchoices[mode=two]{...}{...}{...}{...}
\bookchoices[mode=vertical]{...}{...}{...}{...}
\bookchoices[mode=display,content=math]{...}{...}{...}{...}
\bookchoices[mode=figure,figure={图形主体}]{...}{...}{...}{...}
\bookchoices[mode=graphics]{图形一}{图形二}{图形三}{图形四}
```

标签风格也是参数，不复制一套命令：

```tex
\bookchoices[label=period]{...}{...}{...}{...}   % A.
\bookchoices[label=paren]{...}{...}{...}{...}    % (A)
\bookchoices[label=cnparen]{...}{...}{...}{...}  % （A）
```

页面源码只选择经样式卡片确认的 `mode`、`label`、`content` 和共享 `figure`。`column-sep`、
`row-sep`、`inset`、`figure-gap`、`graphic-max-height`、`label-width` 是类文件校准键，
不能在正文逐题覆盖；否则同一类选择题会发生局部漂移。`trace=true` 只可用于校准夹具，
正文审计会拒绝把它留在最终页面。

需要核对自动决策时，可以临时打开追踪输出；它只写入编译日志，不会印到页面：

```tex
\bookchoices[trace=true]{...}{...}{...}{...}
```

日志中的 `BOOKCHOICES` 行会报告最终模式、标签风格、测得的最宽选项和三个候选
轨道宽度；当前实现分成短的多行 `key=value` 记录，便于脚本解析。追踪只用于类文件
校准和复核，定稿页面不保留它。

实际项目的可用模式、标签和参数必须登记在 `docs/class-api.md`，并以最小文档编译验证。

## 3. 自动模式的边界

自动模式只适合原书没有明确固定版式、且四个选项都是可重复测量的字面内容。类文件应：

1. 在当前版心下计算固定四列、二二和竖排的可用宽度；
2. 把标签和选项合在一起测量最宽候选；
3. 能放进四列时使用四列；否则能放进二二时使用二二；否则使用竖排；
4. 使用固定 `p{...}` 轨道，不使用 `X` 列、`[1m\extracolsep` 或随内容拉伸的列；
5. 不自动缩小字体、不删改选项、不把公式改成图片；
6. 把阈值和间距留在 `.cls`，按本书代表页编译校准；如果选项含任何 LaTeX 控制序列
   （包括公式命令、图形命令、计数器、引用、写文件或自定义宏），必须改用固定模式，
   不让自动测量把有副作用的内容执行两次。

`jjb` 中的具体比例阈值只能说明“先测量再决策”这一机制，不能成为所有中文教材的永久常数。

## 4. 什么时候必须显式指定

以下情况不要交给普通自动模式：

- 原书已经确认是四列、二二或竖排，必须保持原书事实；
- 选项包含展示公式、矩阵、大括号分块、长积分或多行推导；
- 选项与小图、坐标系、表格或几何图形并列；
- 某一选项特别长，自动测量会将其它列压得过窄；
- 选项标签不是当前项目的默认风格；
- 题目属于做题本重排，项目已经为该目标冻结了固定网格。

公式题使用 `mode=display,content=math`，四个参数传**不带 `$...$`、`\(...\)` 或
`\[...\]` 定界符的原始数学内容**；类文件统一使用 `\displaystyle`。`mode=display`
只决定网格和空间策略，不会把普通文字偷偷变成数学，也不会重复包裹已经定界的公式。
图形题使用 `mode=figure`。如果原书版式和自动结果冲突，原书确认结果优先，自动模式只作为未定稿阶段的候选。

建议按下面的决策表写页面源码：

| 页面事实 | 入口 | 说明 |
|---|---|---|
| 普通短文字，代表页未锁定列数 | `mode=auto` | 让类文件测量并选四列、二二或竖排 |
| 原书明确为一行四列 | `mode=four` | 不因某一道题变长而改变整类已确认样式 |
| 原书明确为二行二列，或长选项需要两列 | `mode=two` | 固定 `p{...}` 轨道，保留稳定对齐 |
| 展示公式、矩阵或多行数学内容 | `mode=display,content=math` | 参数传原始数学内容，类文件统一使用 `\displaystyle` |
| 四个选项与同一幅图并排 | `mode=figure` | 图形必须有独立、可审计的图形模块 |
| 每个选项本身都是一幅图 | `mode=graphics` | 每项独立测量、限宽/限高、居中；图形源码仍由项目登记 |
| 四选项单选/多选题 | 同一入口 | 选择题型影响答案语义，不改变选项标签与网格所有权；判断题或其它非四项题先登记接口缺口 |

## 5. 选择题转写规则

- 选项标签绝不在页面源码写 `A`、`B`、`C`、`D` 及其括号或句点；解答正文中原书本来印出的“故选（D）”等选项引用属于正文内容，应照录，不要把它误删；
- 当前公共接口严格面向四选项题；原书只有三项、五项或不完整选项时不要补空项、不要复用第四项，记录样式缺口并由调度者扩展 `.cls` API；
- 类文件会拒绝空选项参数；空参数不是三项题或五项题的占位写法。扩展接口后必须同时更新 API、审计、最小编译夹具和调度提示；
- 不用 `itemize` 加 `\item[A.]` 伪造选项；
- 不在同一项目中混用多个页面级选择题命令；
- 每个组进入时把计数器重置到 `A`；
- 选项中的原文括号、编号、集合符号和数学内容仍属于选项内容，不能被标签解析器吞掉；
- 选项顺序、换行、公式显示方式以源页为准，不因“更漂亮”擅自改写；
- 选项文字读不清时报告存疑，不能从答案、上下文或外部提取器反推。

## 6. 图形选项

`figure` 模式只负责图文两栏容器。图形主体仍需是独立、可编译、可审计的矢量模块，页面命令只引用项目登记的图形接口；不得把源页截图塞进选项，也不得把外部提取器输出的位图当成最终图。

如果图形占据选项本身，而不是四个选项共用一张图，应把它登记为选项媒体所有权，并使用项目专用的图形选项接口，不要把四个选项硬塞进普通文本参数。

## 7. 视觉验收

选择题专项校样至少覆盖：短中文、含行内公式、中长中文、长公式/矩阵、括号标签、图文选项和第二题重新从 `A` 开始。检查：

- 标签是否垂直对齐、是否产生重复或跳号；
- 固定列宽是否让后续选项整体漂移；
- 二二网格的行距是否一致；
- 竖排长选项是否有悬挂缩进和合理换行；
- 公式是否被错误缩小、截断或从显示式变成行内式；
- 图形与选项是否越界、错位或挤压正文；
- 自动模式是否只改变版式，不改变内容。

静态编号审计通过只是必要条件，不能代替编译和独立页面视觉复核。
