# 分页漂移诊断与目录/书签

重建版与原书页数不一致几乎总会发生，也不必然是错误。难点在于**定位漂移发生在哪一章、由什么造成**，而不是对着全书截图猜。本文件给出可复用的诊断顺序，以及目录与 PDF 书签的内部约定。

## 1. 先分清三种“页数”

混用这三种编号是排查页数问题的最大陷阱：

- **物理页**：源 PDF 的文件页序号，包含封面、版权页、空白页、插页等；
- **印刷页**：书内印出来的页码，可能与物理页差若干页，也可能有前言罗马数字、正文阿拉伯数字两套；
- **来源页标识**：本项目 `pages-xxx` / `front-xxx` / `back-xxx`，是重建后的源码标识。

排查前先确认原书这几种编号的换算关系，并写进进度文件。用“总页数减 N”去套一个已知的偏移量，是最常见的错误来源——偏移往往不是常数，因为前置页和插页数量与原书不同。一旦确认某个页文件首注释里的编号其实写的是分块编号而非印刷页号，就要全量校正，不要只在个别章节打补丁。

## 2. 漂移诊断顺序

按“先定位、再归因、最后改”，不要一上来调字号：

1. **建立章节锚点**。记录每章在原书和成品中的起始页，算出各章漂移量。漂移在某些章突然增加，就说明问题集中在那一章，不必查全书。
2. **缩小到具体页**。用 `scripts/audit_page_density.py` 按墨迹密度筛出异常稀疏页（下半页空一大截），这些通常是分页断点。脚本只做定位，不判定对错。
3. **归因到具体机制**。逐页比对候选页与原书同印刷页，常见根因按出现频率排序：
   - **不可分页的语义块**：块内用了 `minipage`、不可断页的盒子、`\parbox` 或浮动体，导致整块被推到下一页，留下半页空白。原书允许它自然跨页时，改成可跨页的分组（`\begingroup...\endgroup` 允许分页）；
   - **浮动体阈值**：原书把图与正文密集混排，默认浮动参数会把可同页的图推成单独图页。调浮动数量和占比参数，而不是缩字号；
   - **环境边界的额外垂直胶**：语义环境的 `begin`/`end` 各自加了 `\medskip` 之类，全书几百个块累计就是好几页漂移。环境边界不应额外占高；
   - **行内公式被写成行间公式**、习题列表局部间距偏大（见 [latex-pitfalls.md](latex-pitfalls.md) 的排查顺序）。
4. **只改机制，不做全局压缩**。找到根因后改 `.cls` 或该环境的实现，保留字体、内容、行距不变，重新编译验证章节锚点是否回到原书。

**“某页空白多”本身不是错误**：原书章末、图页、篇首页本来就稀疏。必须与同印刷页比对后才能判定，不能直接用空白比例当缺陷。

### 页数膨胀的排查顺序

重建版页数与原书不完全一致是正常的，不要为了凑页数硬塞内容。但页数明显膨胀时按根因排查，**而不是先改字号**：

1. 行内公式是否被写成了行间公式（最常见，会把行高成倍放大）；
2. 版心宽度、正文字号、行距、段距是否与原件一致——可以量原书一行排多少字来反推字号和版心；
3. 是否用了 `\flushbottom` 造成间距被拉伸；
4. 列表、引文、框的上下留白是否比原件大；
5. 是否存在不可分页的语义块（见上一节）。

逐项测量后再改，改动集中在 `.cls`，一次只动一个变量并重新比对。

## 3. 分页一致性优先于页数一致

追求绝对页数一致会诱导压缩字号、硬塞 `\vspace`、缩小行距，最后牺牲可读性。更稳的目标是**分页结构一致**：每一章从原书的同一位置开始，章内的自然断点大致对应。用户明确说“不必追求页数完全一致、可读性强就行”时，按这个标准验收，不要为了数字牺牲排版。

## 4. 目录

目录条目和页码的**写入规则**（结构命令自动生成、`toc.tex` 只执行一次自动目录指令、禁止手写条目与页码）属于类文件契约，见 [class-contract.md](../contract/class-contract.md)。本节只记录排版实现（参考用 `titletoc`/`tocloft`）的常见陷阱：

- **页码字号要统一**：目录样式的默认实现会把页码放进条目自身的字号环境，导致章、节、小节的页码随条目字号变化，看起来“有大有小”。要让所有层级都调用同一个页码输出宏；
- **页码盒宽要给够**：页码盒宽设成 `0pt` 会造成逐条 overfull，页码也可能被裁掉；
- **章级条目要有足够左缩进**：否则“第”和章号可能被裁到版心外；
- **点引线（leader）间距**、缩进和对齐由 `.cls` 统一定义，不在模块里逐条调；
- 目录可以自然跨页；续页同样要有页眉和页码；
- **可跳转**：配置 hyperref 的 `linktoc` 让条目文字和页码都能点。不要试图手工包裹整行去覆盖默认链接框——`titletoc` 读回 `.toc` 时会导致未闭合链接错误。用标准方案，稳定优先。

**层级深度要真实**：把 `tocdepth` 数字调大但正文没有对应结构，只会得到空层级。要让目录“多加几级”，得先让原书里“看起来像标题”的内容真正成为结构层级（案例、算法、习题分组等），再由结构命令写入目录和书签。可以用零高度锚点让某个分组进入目录/书签，而不改变正文可见文字。

**分层收录是设计决策**：哪些类型进目录、进到第几级（例如例题本身通常不进目录，但它下面的四级标题要进）要逐类明确并在 API 文档记录，不要靠默认值。

## 5. PDF 书签

书签由结构命令自动建立、页面源码不手工写 `\pdfbookmark`，且目录与书签是两套分别决定的集合——这些规则见 [class-contract.md](../contract/class-contract.md)。实现时注意：

- **一个标题只留一条书签**：给目录项同时加 `\phantomsection` 和显式书签会产生重复条目（同一标题出现两次）。锚点和书签统一到单一路径；
- 书签树应从前置页连续到书末页，层级与文档结构一致；构建后读取 outline 验证深度、顺序和重复项；
- 中文字符串写入 PDF 前要确认编码正常，避免乱码。

## 6. 交付前的分页与导航验收

- 章节起始页与原书的偏差逐章列表，说明每处偏差的原因（真实内容差异、还是仍待修）；
- 目录：条目数、层数、页码对齐、可跳转、续页页眉页码；
- 书签：深度、顺序、无重复、目标页非空；
- 稀疏候选页逐页结论（分页漂移 or 原本稀疏）。

## 7. 分页模型

不同部分的自然节奏不同，按原件决定，不要全书一刀切，也不要靠 `\newpage` 硬凑：

- 前言、正文段落、注解：**自然分页**，让内容自己流动。原书这一页排满了不代表重建版也要排满；不要为了对齐原书页数或版式插入强制分页、加 `\vspace` 或压缩内容；
- 章、篇起页：原件通常**强制另起一页**，用 `.cls` 里的一条集中开关实现，而不是在每个 `pages-xxx.tex` 里手写 `\newpage`；
- 独立模块的封面与扉页、做题本：按目标单独决定。

分页开关和前后距一样属于 `.cls` 的集中样式，逐页源码只提供标题语义。

前置页必须与正文页码解耦：用 `\frontmatter` 承载封面、目录、序言、献词（不显示正文页眉页脚，页码用罗马数字或留空），用 `\mainmatter` 让正文从 1 重新开始。这样新增前置页不会污染原书正文页码，正文页与原书印刷页才能对得上。前置页增删时只影响前置自身。

新增前置页会让成品物理页相对原书整体平移；复核时始终用最终页面标识定位，不要用物理页号，也不要手工去“把某一页减 2”。
