# 图形与资产重建

扫描教材里的“图”分两类，处理方式完全不同。先分类再动手，不要一律用同一种办法。

## 1. 结构图：用 TikZ 重画

树形图、思维导图、知识结构网络图、流程图、框图、时序图、数轴、坐标系、阴影区域、花括号分层等，只要能用坐标和节点表达，就用可编译的 TikZ 重建：

- 树形层级用 `forest` 或 `tikz` 的 `child` 语法；原书有几级就画几级，保留分支结构；
- 花括号、框线、箭头方向严格按原件；原件用花括号分层的，不要自作主张改成折线树；
- 同一类图在全书要用同一个 `.cls` 宏或同一个模板，只在节点文本和结构上不同；不要每页重写一份坐标代码；
- 图内的文字、公式、标注属于图形内容，用矢量字形排版，不贴截图。

## 2. 书法字、标志、题字：矢量描摹，不换相近字体

封面题字、校名、印章、手写签名、艺术字这类**字形本身就是内容**的元素，不能用“找一个差不多的字体打出来”来代替——那会直接改变原件的视觉身份。正确做法是从原件高分辨率图像描摹成矢量：

- **取最高分辨率的原页作为唯一母版**。整页内嵌图通常比任何裁剪、缩略版本都清晰（有时能到 300 ppi 上下）；不要拿已经被压缩或裁切过的副本去描摹；
- 描摹成 Bézier 轮廓矢量，逐轮调整阈值，保留原字的骨架、笔压和非均匀字距；
- 多轮清理时**只清小面积内部噪孔**，保留“雪”“埋”这类真实的大型负形；不要改变外轮廓；
- 输出**纯白蒙版**（只含白色路径和透明度），**不把颜色烘进资产**。颜色由 `.cls` 的宏在渲染时给，这样换主题、换底色都不需要重新描摹；
- 用**像素级比对**收敛：量原字与矢量的外接框（bbox）宽高和位置，逐轮逼近。差 1–2 px 属于可接受范围；差一成说明阈值或缩放还没对；
- **保留描摹脚本**。它属于可复现源码，不是一次性产物；下次原件更新或要生成不同尺寸时能重跑。

如果原件图是照片或连续色调、无法诚实矢量化，按硬规则暂停并询问用户，不要塞位图。

## 3. 资产组织

- 共享矢量资产（题字、蒙版、校徽、装饰条）放**独立的资产目录**，不要散落在页面源码里；页面只引用稳定 ID；
- 资产的尺寸、颜色、位置写成 `.cls` 宏，页面和脚本都从宏取值；不要在页面源码、描摹脚本和类文件里各写一份同样的色值或坐标；
- 图形模块按所属分区命名（如 `figure-pages-023-001.tex` 或按章 `chapter-7` 的图形集），模块内只定义可嵌入主体，不含浮动体、题注、编号、页码；
- 页面通过类文件的集中接口嵌入（参考 `\bookfiguremodule{...}`），不在页面源码写裸路径。

## 4. 收敛循环

每张图独立走“编译 → 渲染 → 与原件并排比对 → 修改”循环，通过后再确认它在正文中的大小、基线、环绕、题注和分页：

- 逐图比对，不抽样；一张不合格就继续，不要用“整体还行”放过；
- 独立编译图形本身，再编译嵌入后的正文页面，两个层次都要过；
- 图注的编号、字号、格式与原件一致；编号由计数器产生，不手写；
- 原书没有引用的图号和“见图 x.y”式引用不得由转写补造（见主文件硬规则）。

多张图彼此独立时，可以按分区或章节分组并行推进，但每张图仍要单独走完闭环，主执行者统一复核。
