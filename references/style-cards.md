# 样式卡片

样式卡片是内容执行单元识别页面样式的唯一摘要来源。卡片只引用最终页面标识和源文件路径，不复制页面，不记录 PDF 物理页。

## 字段

| 字段 | 要求 |
|---|---|
| `style_id` | 稳定 ID，例如 `body-prose`、`example-box`；这是文档 ID，不是 LaTeX 环境名 |
| 页面分型 | 可观察的输出页面类别，例如封面、目录、章节首页、普通正文、图表/公式页、参考文献/索引、封底；`publication-info` 和 `cover-facsimile` 只在输入审计中记录，不作为输出样式；不是 LaTeX 环境名 |
| 语义角色 | 正文、标题、定义、例题、习题、答案、媒体等 |
| 环境/命令 | `.cls` 中已经实现并编译验证的 ASCII 标识符 |
| 视觉特征 | 字体/字号、行距、缩进、边框、底色、间距、对齐和分页行为 |
| 辨识条件 | 如何从相邻样式和页面结构判断该卡片 |
| 显示视图 | `full`、`body`、`knowledge`、`examples`、`exercises`、`workbook` 等实际模式 |
| 代表页 | `front-001`、`pages-023`、`back-004` 及对应源文件 |
| 状态 | `待覆盖`、`待复核`、`已确认`；只有已确认卡片可分发 |

## 选择规则

先按视觉和语义差异选页，不按“每章一页”机械采样。先建立页面分型清单，再在每种实际存在的类型中选代表页；至少覆盖：

- 封面、献词/序言、目录、章节首页、普通正文、封底或其他书末页；仅含版权/出版/印刷信息的证据页随后舍去，不创建对应输出模块；含独有内容的混合页按其保留内容选择代表页；
- 纸张、版心、单双面奇偶页，以及尺寸稳定页和尺寸漂移/边框异常页；
- 各级标题、普通正文、列表、引文、脚注/边注、页眉页脚；
- 公式、定义/定理/证明、例题、习题、答案/解析/提示（原件存在时）；
- 图、表、树结构图、流程图、硬件框图、网络时序图、题注，以及原件实际存在的特殊页；
- 参考文献、索引、附录或参考链接页（原件存在时）；
- 跨页知识块、跨页题目和类文件生成的目录/页码/页眉页脚。

纸张和版心先查书内版权/出版/印刷信息中的开本、成品尺寸或纸张规格，再由多张代表页共同确认：对稳定尺寸取共同范围，对轻微漂移记录容差，对明显异常 `MediaBox`、印刷信息与页面几何冲突或无法判断的物理纸型标为“待人工确认”，不得让单页异常值进入 `.cls`。一个页面可以覆盖多个卡片，但同一页只记录一次源标识。新增变体时新增卡片或明确扩大现有卡片的辨识条件，不复制代表页。

教材不一定有题目环境。若没有例题或习题，卡片中将其标记为“不适用”，并在构建矩阵中省略对应做题本；不得为了满足覆盖清单而虚构题目样式。

## 分发格式

```text
样式摘要版本: v3
- chapter-opener: 章节首页；标题和章眉的特殊留白；视图 full/body；源页 pages-017
- body-prose: 普通正文环境；五号宋体，首行缩进，固定段距；视图 full/body；源页 pages-023
- example-box: bookexample；带编号标题和边框；允许嵌套 bookanswer；视图 full/examples/workbook；源页 pages-041
- answer-block: bookanswer；题目内子所有者；workbook 隐藏；源页 pages-042
```

若卡片不能表达原页可见差异，执行单元必须暂停并报告，不得用最相近样式代替。
