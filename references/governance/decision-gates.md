# 必须询问用户的决策门

有些判断**只能由用户做**：涉及权利、意图、或证据不足以可靠推断的选择。agent 的职责是**在正确的时点主动提出**，并给出足够信息让用户快速决定——不是自己猜，也不是等到做完才发现方向错了。

## 0. 两条通用规则

1. **到点就问，不要攒着**。决策门有明确的触发时点（见下表）。相关阶段一旦到达就先问清楚再动手，不要"先做一版看看"——返工成本远高于问一句。
2. **提问要带证据和候选**。不说"纸张尺寸不确定怎么办"，而是"书内版权页印的是 185×260mm，页面几何实测 185.2×260.1mm，是否按 185×260mm 建类文件？"。给候选、给依据、给默认建议，用户只需确认或改。

**不要问的事**：能从事实验证的东西（页数、是否缺页、能否编译、审计是否通过）自己去查，不要拿这些占用用户的注意力。

## 1. 决策门清单

| 时点 | 必须确认什么 | 为什么不能自己定 |
|---|---|---|
| 阶段 1 输入审计后 | **原书纸型**（印刷规格 vs 页面几何一致时确认；不一致/缺失时必须问） | 纸型是所有版式的基准，猜错全书返工；且"常见开本"不能替代原件证据 |
| 阶段 1-4 发现证据页 | **舍去页范围**（`cover-facsimile`、`publication-info` 等）与**混合页处理** | 舍得以致丢内容不可逆 |
| 阶段 4 命名前 | 前后置**模块清单**：原件实际有哪些（封面/前言/献词/目录/后记…） | 原件缺的不得伪造、有的不得漏提取；"标准结构"不能替代原件 |
| 阶段 5 样式提取后 | **样式变体判定**：同一类型的差异是变体还是噪声 | 需要人对照原件裁夺；agent 无权把变体当噪声忽略 |
| 阶段 7 样式复核 | **校样确认**（达到 90% 且无未分类警告后） | 未确认不得进入批量转写 |
| 阶段 12 首次构建做题本前 | **入口形态**（单入口 + 类文件开关，还是独立做题本入口） | 见第 2 节；两种都正确，取决于做题本与完整书的差异大小 |
| 阶段 12 构建矩阵前 | **主题集合**、**做题本范围**（`examples`/`exercises`/`all`） | 不把额外主题或空做题本当默认交付 |
| 阶段 14 最终复核 | **发布结论**（已知差异是否可接受） | 人工门槛 |
| 阶段 15 发布开源 | **发布范围 / 权利状态 / 可见性** | 涉及他人著作权与对外发布，见 [release-and-open-source.md](release-and-open-source.md) |
| 任意阶段 | **读图能力缺失**（本层或子代理无法读图） | 需用户切换模型；禁止用 OCR 顶替 |
| 任意阶段 | **无法诚实矢量化的图**（照片、连续色调） | 塞位图违反硬规则，只能由用户决定取舍 |

## 2. 阶段 12：主动确认做题本入口形态

**首次构建做题本之前，调度者必须主动问**，不要让用户自己想。判断依据是"做题本与完整书的前后置差异有多大"。

提问模板（给候选、给依据、给建议）：

```text
做题本要开始构建了，需要先定入口形态（两种都支持，都不复制题目源码）：

A. 单入口 + 类文件开关 —— 做题本差异全部由 .cls 条件命令控制
   适合：做题本的封面、目录、页眉与完整书大体相同，差异集中在题目筛选与作答区
B. 独立做题本入口（main-workbook.tex + 专用前后置模块）—— 题目仍复用同一份 pages-xxx.tex
   适合：做题本需要专门的封面/目录/页眉（例如只列题目范围的目录、按画布重排的页眉）

我从当前项目看到的情况：<封面/目录/页眉与完整书的差异描述>。
因此建议 <A 或 B>；两种都不复制题目内容，只是入口组织方式不同。
请确认用哪一种。
```

**判断提示**（供调度者对照原件给出建议）：

- 做题本的封面要换名字、换配色、换标识 → 倾向 **B**；
- 做题本目录只列题目范围、或按题型重排 → 倾向 **B**；
- 做题本页眉页脚要按画布重排（横向 Pad）→ 倾向 **B**；
- 以上都与完整书相同、只是少答案多留白 → **A** 足够且更简单。

选定的形态要写进 `progress.md` 与 `docs/class-api.md`，因为它是后续构建脚本与审计的前提。

## 3. 阶段 15：发布与开源

发布是**用户显式触发**的可选阶段。一旦触发，动手前必须确认三件事：

1. **发布范围**：只发布工具链，还是连同重建正文？
2. **权利状态**：含正文时，是否已获原书权利人许可？
3. **可见性**：私有 / 公开 / 仅本地提交？

在用户明确回答前，只能停在本地产物准备。详见 [release-and-open-source.md](release-and-open-source.md) 第 2 节。

## 4. 提问方式

一段好的询问包含四点，缺一项用户就要反问：

- **卡在哪**：哪个阶段、哪个页面/模块；
- **证据是什么**：读到什么、量到什么、来自哪一页；
- **候选有哪些**：两三个具体选项，含各自影响；
- **建议与默认**：推荐哪个以及为什么。

反面例子（不要这样问）：

```text
纸张尺寸好像不太对，怎么办？            ← 没有证据、没有候选
我按 A4 做了，你看行不行？               ← 已经动手了才问，且没给原书证据
```

正面例子：

```text
阶段 1 输入审计发现纸张证据冲突，需要你定：
- 版权页印的成品尺寸是 185×260mm；
- 我实测 12 页的 MediaBox，稳定值 185.2×260.1mm，另有 2 页因扫描漂移 184.6×259.5mm。
两者一致，建议按 185×260mm 建类文件，漂移页按正常页处理。
请确认。
```
